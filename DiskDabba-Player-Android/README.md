# DiskDabba Player (Android Native) 📱🎬

The official native Android video player application for [DiskDabba](https://diskdabba.com), built with **Kotlin**, **Jetpack Compose**, and **AndroidX Media3 ExoPlayer**.

---

## 🎨 UI & Features

Designed to match the modern purple/lavender visual identity of DiskDabba:

* **🏠 Home Screen:**
  * One-tap paste link input card (`Enter link here ...`) with search & play action.
  * **Recent History:** Local playback history tracking positions so you can resume playback anytime.
  * **Go Premium PRO** banner and floating quick-folder action button.
  * 3-tab Bottom Navigation (`Home`, `Saved`, `My Profile`).

* **📄 File Details Screen:**
  * Lavender circular video hero container with file name, MIME type, and size (`video • 120.6 MB`).
  * 2×2 metadata grid (`Size`, `Type`, `Uploaded`, `Uploader`).
  * Circular action buttons (`Bookmark`, `Share`, `Save to Cloud`).
  * Seamless one-tap launch into DiskDabba Player.

* **▶️ Video Player (AndroidX Media3 ExoPlayer):**
  * Hardware-accelerated HTTP Range streaming (direct Backblaze B2 / Cloudflare R2 vault).
  * Fast seeking, ±10-second skip gestures.
  * Double-tap gestures: double-tap left to rewind 10s, double-tap right to forward 10s.
  * Playback speed selector (`0.5x`, `0.75x`, `1.0x`, `1.25x`, `1.5x`, `2.0x`).
  * Fullscreen landscape orientation toggle.
  * Position restoration / resume playback.

* **🔖 Saved Screen:**
  * Bookmarked videos saved in local Room database (no mandatory login or account required).
  * Search and manage saved videos.

* **⚙️ Settings Screen:**
  * Theme switcher (Light, Dark, System adaptive).
  * Subtitle settings, Download preferences, Privacy controls.
  * Real-time DiskDabba API connection indicator.

## 🔗 Shared-Link Opening & Android App Links

DiskDabba Player registers verified intent filters for:
* `https://diskdabba.com/v/*`
* `https://diskdabba.com/app/*`
* `diskdabba://v/*`

When a user taps any shared video link:
1. If the app is installed, Android App Links opens the video directly in the native player.
2. If the app is not installed, the browser opens the responsive DiskDabba web player.

The verification file is hosted at:
`https://diskdabba.com/.well-known/assetlinks.json`

## 🚀 Building & Testing

### Prerequisites
* Android Studio (Ladybug / Koala or newer)
* JDK 17 or newer
* Android SDK 35 (Android 15)

### Build Debug APK
Run the following from the `DiskDabba-Player-Android` root:

```bash
# Windows
gradlew.bat assembleDebug

# macOS / Linux
./gradlew assembleDebug
```
The output APK is generated at:
`app/build/outputs/apk/debug/app-debug.apk`

### Build Production Signed Bundle (AAB) for Google Play
```bash
./gradlew bundleRelease
```
The output bundle is generated at:
`app/build/outputs/bundle/release/app-release.aab`

## 📲 How to Install & Test on Your Android Phone

1. **Option A: USB Debugging (Fastest)**
   * Enable Developer Options on your phone: `Settings > About phone > Tap "Build number" 7 times`.
   * Enable `USB Debugging` in `Settings > Developer Options`.
   * Connect your phone to your PC via USB.
   * In Android Studio, select your phone in the device dropdown and click **Run (Shift+F10)**.

2. **Option B: Install APK via File Transfer / WhatsApp / Google Drive**
   * Copy `app-debug.apk` to your phone (via USB cable, Telegram, WhatsApp, or Google Drive).
   * Tap the `.apk` file on your phone.
   * Allow "Install from unknown sources" if prompted.
   * Tap **Install** and open **DiskDabba Player**.

3. **Test Link Resolution:**
   * Open the app.
   * In the top input box, paste any valid DiskDabba video link (e.g. `https://diskdabba.com/v/your-file-id`).
   * Tap the search/play button. The app will fetch metadata and start streaming instantly.

## 🛡️ Security & Privacy
* Zero database service-role keys or storage bucket secrets are bundled in the app.
* All access uses authorized presigned streaming tokens generated by the DiskDabba backend.
* Public videos stream directly without requiring user registration.
