## Cloudflare Development Guidelines
When interacting with Cloudflare, use the cf CLI unless the project has a Wrangler configuration file (`wrangler.jsonc` or `wrangler.toml`).

## Model Context Protocol (MCP)
- Cloudflare Remote MCP: `https://mcp.cloudflare.com/mcp`
- Configuration file: `.vscode/mcp.json` and `.mcp.json`
